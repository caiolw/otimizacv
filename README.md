# OtimizaCV

Ferramenta proposta para analisar currículos junto com a descrição de uma vaga e indicar o que impede o documento de ser lido corretamente por sistemas de triagem automática (ATS).

**Projeto Interdisciplinar I · Gestão da Tecnologia da Informação · IFPR · 2026.2**

Página do projeto: https://caiolw.github.io/otimizacv/

Protótipo: https://caiolw.github.io/otimizacv/app/

Proposta e documentação concluídas. Há um protótipo da interface em [`app/`](app/), que roda inteiramente no navegador (detalhes em [app/README.md](app/README.md)).
